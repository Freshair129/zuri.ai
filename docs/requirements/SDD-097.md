```text
| SDD-097 | Secret store selection by reference prefix: a `secretRef` names its store — `supabase-vault:<uuid>`, `envelope:<uuid>` or `deployment-secret:<name>` — and the LINE runtime composes a dispatching secret manager that routes a prefix to its adapter only when that adapter is configured; `ZURI_SECRET_STORE` (`supabase-vault` or `envelope`) chooses the one store an installation writes to, and a reference whose prefix has no configured adapter resolves `Unavailable`, never read from another store. The Supabase store encrypts in the database through `SECURITY DEFINER` write, activate, revoke and resolve functions over the public Prisma tables, called under dedicated NOLOGIN writer and reader roles; the envelope store encrypts in the app with AES-256-GCM under a random per-secret data key wrapped by a key-encryption key from the environment, binding Tenant, Business, connection and credential version as additional authenticated data. The Phase-1 model-credential resolver is left unchanged. | FR-223; SEC-030; ADR-089 D1 |
```
