| SDD-023 | `FileAsset` + validated `FileLink` form the portable file metadata graph; `LocalWorkspaceMount` maps one device-local absolute root to stable relative paths. Managed ingest is staged and audited, missing files require explicit reconcile/relink, cache entries carry source revision and are disposable, and the legacy ProjectFile API remains behind a migration adapter until ZV2-CR-001 parity/rollback gates pass. **Containment is Windows-path-based**: `local-files/` resolves through `path.win32` so it can reason about drive letters, UNC roots and junction/reparse escape (SEC-007), which makes the managed local workspace a Windows-only capability — the rest of the product is portable. | FR-045; ADR-016, BR-010, NFR-009, SEC-007 |
