| SDD-056 | Bundle Import Orchestrator shape (ADR-049 D3/D8): five modules under `src/modules/project-manager/import/bundle/` — `bundle-schema` (runtime Zod validator aligned with the JSON Schema), `bundle-resolver` (bundle-local symbol and scope resolution), `bundle-dry-run` (combined preview), `bundle-commit-service` (atomic-mode commit reusing the PM application services), `bundle-receipt` (idempotency and audit lineage). The orchestrator is the only bundle-side caller of the strategy and PlanEnvelope services; the routes stay thin transports. First implementation documents atomic mode; a future external-owner bundle must switch to the coordinated state machine ADR-049 D8 specifies rather than pretending distributed atomicity. | ✅ implemented 2026-08-27 |
