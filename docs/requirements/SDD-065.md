# ZAI:SDD-065

<!-- canonical-row:start -->
```text
| SDD-065 | Cross-tenant deduplication is made inexpressible rather than forbidden. The tenant is folded into the ingestion identity hash itself, so two tenants holding a byte-identical document cannot produce the same key and there is no comparison to prohibit — a rule enforced by what can be constructed outlives one enforced by a check that has to fire, and a check can be deleted by someone who reads it as redundant. Section 11 lists five dedup strategies and this implements three: exact checksum, canonical checksum and source-native id, all of which read what the artifacts say about themselves. Content similarity and structural similarity are declined, and not merely as unimplemented: both require a threshold, and a threshold chosen in this module would be a judgement about which documents count as "the same" made by whoever typed the number and inherited by everyone after. The same reasoning declines inferring a lineage from a filename — `contract-v1.pdf` beside `contract-v2.pdf` is a hint a human left, not a claim the system can verify. | FR-117; SEC-021, BR-021, FR-081, FR-116, ADR-050 |
```
