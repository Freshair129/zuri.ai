| FR-289 | Zuri Knowledge Studio is an installation-operator-only, read-only browser for the indexed Zuri Markdown document graph. Operators can search and browse documents, filter graph nodes by kind and neighbor hops, use domain groupings derived only from explicit graph relations or document metadata, inspect each node's exact source path, and read its Markdown in a same-page viewer. Domain ownership is never inferred from directory names; explicit metadata and graph relations determine a unique domain grouping. When no unique domain exists, sources under docs/services are grouped in Services (unassigned), and other sources are grouped in Shared (unassigned). The graph and Markdown come only from the generated document graph and available repository source files. The original graph component must run on the operator's browser machine at a loopback origin; the view reports unavailable when it cannot connect, and Zuri does not host or redistribute the captured component bundle. The page and each graph or document API request require installation-operator authority and fail closed for node IDs absent from the graph, unsafe paths, or missing source files. | planned |
