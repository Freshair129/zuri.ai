# ZAI:SDD-068

```text
| SDD-068 | Field-name mapping between stage functions is made explicit and singular, never left for each caller to reconstruct. FR-116 names an artifact's content hash `checksum` (spec §8); FR-117 names the identical value `content_hash` (spec §29, BR-021). Two accurate module-local names for one fact is correct inside each module and a hazard at their boundary — a caller supplying two copies keeps them in sync by discipline, which is the exact shape BR-021's own field-separator defect took (a hand-written comparison of two keys, made without reading the one compared against). `runKnowledgeIngestionStages` takes `content_hash` once, from the artifact, and renames it to `checksum` in exactly the one call that needs the other name. The same discipline governs a chunk's `scope`: FR-111 classifies against `{ scope: { tenantId, businessId }, sensitivity, ... }`, but a chunk's `scope` field carries the identity pair alone — the shape the FR-111-into-FR-112 seam test already fixed — never the whole classification object, which would nest a field named `scope` inside a field named `scope`. | FR-118; FR-111, FR-112, FR-116, FR-117, BR-021 |
```
