# ZAI:SDD-067

<!-- canonical-row:start -->
```text
| SDD-067 | A knowledge ingestion run input is derived whole from the artifact's ingestion identity, its correlation id included, because FR-071 compares more than the key. `createPipelineRun` returns `UNCHANGED` for a repeated `idempotencyKey` only when `requestHash` also matches, and that hash covers the entire parsed input — so a second ingestion of the same artifact carrying a fresh correlation id raises 409 `idempotency key was reused with different input` rather than being the no-op BR-021 requires. `knowledgeIngestionRunInput` therefore computes every field from the artifact, and re-ingestion is byte-identical by construction rather than by the caller remembering to make it so. The cost is stated rather than hidden: the second attempt's own correlation is not recorded, because there is one run and it was correlated once. Relaxing FR-071's comparison to the key alone was rejected — that comparison is what catches a key reused for genuinely different input, and weakening it for one definition weakens it for the definition already relying on it. | FR-109; FR-071, BR-021, SDD-057, SDD-066, ADR-050 |
```
