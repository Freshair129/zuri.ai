```text
| SEC-030 | Channel and provider credential material is write-only: no API response, log line, audit payload, error message or cause, backup snapshot, Prisma column or client state beyond one input's lifetime carries it, whichever secret store holds it. A credential is displayed only as a mask plus the last four characters of its non-secret identifier, never any part of the secret or token; request bodies are refused with a generic 400 that reflects no field value; store functions run as `SECURITY DEFINER` with pinned search paths and execute rights granted only to dedicated NOLOGIN writer and reader roles, and no application role may read the vault views; envelope-store ciphertext is excluded from backup export and its key-encryption key is never exported; Prisma query logging is off on the write path. | 🔜 declared only 2026-09-14 — FR-223..FR-225 / ADR-089 D2 security gate |
```
