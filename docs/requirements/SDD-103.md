# ZAI:SDD-103

<!-- canonical-row:start -->
```text
| SDD-103 | An archive file is `<tenantId>/<yyyy>/<runId>.zca`: a header with format version, Tenant, run id, key version and creation time, then one sealed segment per Customer (IV, wrapped-key reference, ciphertext, tag) whose plaintext is gzipped JSON Lines, one line per message with its message, session, conversation, Customer, Business and Tenant ids, direction, content kind, body, reply source, created time and attachment metadata. The writer creates the file under a temporary name, flushes and fsyncs it, renames it into place and reads it back to compare SHA-256; only then do the manifest row and the tombstones commit in one transaction. The archive directory reaches the web container only through `docker-compose.cold-archive.yml`, named in `COMPOSE_FILE` and mounted at `/archive`. | ADR-093 D2, D3, D4 |
```
