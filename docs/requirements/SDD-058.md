```text
| SDD-058 | Knowledge ingestion stage execution location is policy-driven, not deployment-driven. The specification's split (Stages 1–8 local edge, 9–14 cloud GKS, 15–17 selected execution) is an illustrative default, not the contract: the binding input is the data's own classification, so RESTRICTED knowledge carrying `cloud_processing_allowed = false` runs all seventeen stages locally and no topology or environment change may override that. Location is therefore resolved per object from FR-111's policy fields at each stage boundary, never read from deployment configuration — a data boundary that configuration can widen is not a boundary. | FR-111; FR-109, SEC-021, ADR-041, ADR-050 |
```
