# ZAI:BR-028

<!-- canonical-row:start -->
```text
| BR-028 | Customization is irreversible: once raw stock is branded it is a different, customer-dedicated product and can never return to generic stock — a completed customization work order does not receive its input SKU back. It receives a product whose `itemKind` is `CUSTOM_COMPONENT` carrying `dedicatedCustomerId` and `dedicatedSalesOrderId`, and the domain refuses by code to issue that product for another customer, to transfer it into a raw-stock location, or to consume it in a kitting order for another sales order. Disassembly obeys the same rule: a branded component comes back branded or goes to quarantine, never as raw stock. The single exit is an explicit ADJUSTMENT write-off with a stated reason, which is a decision a person makes and the audit records. | FR-176; FR-178; ADR-074 D4, D6 |
```
