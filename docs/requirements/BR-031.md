# ZAI:BR-031

<!-- canonical-row:start -->
```text
| BR-031 | What is already promised is subtracted before anything else is promised — `ATP = onHand − Σ committed reservations − Σ live quote reservations`, where a quote reservation is soft and expiring (7 days by default) and an order reservation is committed against a confirmed sales order. A reservation never writes the stock ledger, because a promise is not a physical fact and mixing the two would make on-hand disagree with a shelf; and a reservation is never deleted, only `RELEASED`, `CONVERTED` or `EXPIRED`, so a past refusal to promise stays explicable. Expiry is evaluated on read against the clock, so an ATP figure is correct whether or not a sweeper has run. | FR-180; ADR-074 D8 |
```
