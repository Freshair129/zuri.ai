```text
| SDD-085 | Edge extraction is one pull-model job record, not a cloud→device callback: the cloud owns `AssetExtractionJob` and its lifecycle (QUEUED → CLAIMED → COMPLETED \| FAILED \| CANCELLED), the device claims the oldest QUEUED job **of its own credential's Business** under a 10-minute lease, and an expired lease returns the job to QUEUED for another attempt rather than stranding it. Result validation reuses the FR-138 `zCandidate` schema exported from one shared module, so the OpenAI and edge adapters validate identically by construction; evidence bytes are streamed by the cloud to the lease-holding device only, never as a storage URL or credential. | FR-143; FR-144; SEC-025; ADR-059; ADR-041 |
```
