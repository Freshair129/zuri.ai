# ZAI:SDD-091

<!-- canonical-row:start -->
```text
| SDD-091 | An agent tool is a thin adapter over an application service and adds no authority of its own: each SmartGift tool takes the caller's already-resolved viewer, calls the same exported service a page or route would call, and returns its result — no direct Prisma query, no scope assembled from tool arguments, no Business id the caller did not already prove. The split across the two existing registries is by effect, not by convenience: read tools land in the Gate E `createToolRegistry` (which refuses anything not `readOnly: true`) and write actions in the Gate F `createWriteToolRegistry`, where the two irreversible dispatches declare `HIGH` sensitivity so the action gate demands step-up. Tool JSON schemas are generated from the same Zod contracts the services parse, so a tool cannot advertise a shape the service would reject. | FR-181; ADR-074 D9; ADR-007 §P6, §P7 |
```
