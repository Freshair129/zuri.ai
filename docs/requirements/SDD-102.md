# ZAI:SDD-102

<!-- canonical-row:start -->
```text
| SDD-102 | One function assigns a message's session inside the admission transaction: it writes the `Conversation` row first, which takes that row's lock on Postgres and serializes on SQLite, then reads the latest message time of that conversation, and either reuses the latest session or inserts a new one and writes the previous one's `closedAt`. The idle comparison uses the new message's provider timestamp, never the server clock, so a delayed webhook lands in the sitting it belongs to. Reply recording reads the session from the inbound message it answers. The MSP session id returned by an append is stored on the session row; a later, different MSP id for the same session is recorded as a divergence and never overwrites the first. | ADR-094 D1, D2 |
```
