# ZAI:SDD-059

```text
| SDD-059 | Chunking is a pure calculator in the knowledge lane, with no persistence and no model. `src/modules/knowledge/chunking.js` takes parsed blocks plus a scope and a provenance and returns chunk objects; it opens no database, writes no table and declares no Prisma model, so the knowledge charter's `owns_models: []` stays true (SDD-057, ADR-050). Persisting chunks is a later slice and will need a charter change — pinning the boundary here makes it a decision rather than an oversight. Token counting is a whitespace approximation on purpose: a model tokenizer would couple Stage 7 to whichever embedding model Stage 15 happens to use, and this number exists to choose a split point, not to be billed against. Exactness belongs at the embedding boundary, where the model is known. Current scope clarification (ADR-073, 2026-09-08): chunking.js remains pure. The approved separate GenesisRAG17 adapter now persists KnowledgeRawArtifact, KnowledgeParsedArtifact and KnowledgeChunk through repository interfaces; the charter lists its seven models. The historical owns_models-empty and persistence-pending statements apply to this original calculator slice, not the current adapter. | FR-112; FR-109, FR-111, BR-021, SDD-057, ADR-050 |
```
