```text
| BR-032 | A tradeable finished set carries the FlowAccount normalized item code — `^[A-Z0-9]+-[0-9]+\([A-Z0-9_-]+\)$`: factory model, item count, package code (`TMS06-4(P-16)` is a four-item set in box P-16) — and a kitting work order is refused when its output has none, or one that does not match. The code is an **external** identifier and is stored as an attribute, never a key (BR-002): `Product.flowAccountSku`, unique per `(tenantId, flowAccountSku)`. It is not `Product.code`, whose FR-154 pattern deliberately has no room for parentheses, and not an `ExternalRef` row, because that table is unique installation-wide and two Tenants may legitimately sell a set the same factory model names. Components and packaging carry no such code at all, because they are never synchronised to FlowAccount. | FR-177; ADR-074 D5; BR-002 |
```
