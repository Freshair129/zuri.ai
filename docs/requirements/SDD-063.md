| SDD-063 | The parser produces the block shape Stage 7 already consumes. `parseDocument` returns `structure` as an array of `{ type: heading or text, level, text }`, which is exactly the `blocks` argument `chunkDocument` reads — so Stage 2 hands Stage 7 its input rather than the two agreeing by coincidence across two test suites that each build the shape. **Stage 7 owns the shape**; it existed first and its tests define it, and the parser conforms to it. The seam is held by a test that feeds real parser output straight into `chunkDocument` and asserts on the resulting chunks, because a written statement that two shapes match is prose, and prose is not a contract — the same reason a green governance run does not prove a link resolves. Markdown and plain text are parsed here; PDF, DOCX, OCR and vision layout are not, and are received instead through FR-071's `smartgift.document-intake.v1` front door, which validates someone else's extraction rather than performing one. | FR-115; FR-112, FR-071, FR-109, ADR-050 |
