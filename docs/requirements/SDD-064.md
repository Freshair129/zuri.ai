# ZAI:SDD-064

```text
| SDD-064 | Declaring knowledge derived is a claim that names its sources, not an exemption from having any. Spec §8 forbids publishing a Fact or Relation whose source cannot be traced "unless explicitly declared DERIVED / INFERRED / COMPUTED", which read naively is an escape hatch: type the word and the requirement lifts. The declaration therefore exempts an object from having a RAW source and never from having sources — an object that declares itself derived and can name nothing is not derived, it is unattributed, and it does not publish. Naming is not enough either: `assertPublishable` requires a resolver and refuses a named source that nothing resolves, because a check that accepts an unresolvable name lets the declaration back itself, which is the laundering this decision exists to stop arriving through the door the decision built. There is deliberately no shape-only mode; whether a named source exists is the question, and a permissive default would answer a different one. | FR-116; FR-071, FR-112, FR-113, SDD-042, ADR-050 |
```
