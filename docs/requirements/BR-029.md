| BR-029 | A bill of materials declares the loss it expects, and the buffer is issued up front — `ProductRecipe.scrapAllowanceFactor` is a fraction in `[0, 0.20]` (default 0, so every recipe predating it is unchanged), and the gross issue for a net requirement of Q is `ceil(Q × (1 + factor))`. What the buffer did not consume is reconciled at completion and stays where it is; what it did not cover is reported as a shortage that blocks the work order (`BLOCKED_SHORTAGE`) rather than a build that half-happened. Scrap is issued to the quarantine/scrap location so the loss is visible as a movement, never as a quantity that merely failed to arrive. | FR-176; FR-177; ADR-074 D5 |
