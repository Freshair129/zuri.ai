```text
| SDD-072 | FR-118's seven stage-invocation steps are extracted into one shared definition (`TIER1_STEPS`) that both `runKnowledgeIngestionStages` and a new `runKnowledgeIngestionStagesWithTrace` iterate, so the field mappings — checksum from content_hash, a chunk's scope as the identity pair alone, and the rest SDD-068 already named — are written once rather than duplicated between a throwing caller and a trace-collecting one. `runKnowledgeIngestionStages` keeps its exact throw-on-first-failure contract; all fifteen of its existing tests pass unchanged, because its observable behaviour did not change, only its internals. The new function never throws itself: a stage's exception becomes data (`{success, stages, envelope, partialEnvelope, failedStage, error}`), because the reason to call it instead of the throwing version is to keep going long enough to report where it stopped. `errorRef` stays redacted on the FR-071 ledger, per that contract's own repeated description of `PipelineRecordEvent`/`PipelineStep` as carrying "redacted" evidence, most concretely AC-071.28 ("agents emit only append-only, redacted events"). This was a **caller-side convention with no contract enforcement** at the moment this slice was written — `errorRef: z.string().max(1000)` accepted anything. A peer session found the same gap independently while reviewing this slice and closed it separately: `errorRef` is now a validated reference token (SDD-073, `/^[A-Za-z0-9][A-Za-z0-9._:/#@-]*$/`, max 200). Both `errorRef` values this slice writes — `ki-quarantine://{identity}/{stage}` and `ki-quarantine://{identity}/record` — were checked against that pattern directly before this row was written and conform with room to spare. `error_message` (BR-022's field) therefore lives only in the quarantine envelope this executor returns to its own caller; the ledger's `errorRef` holds a stable reference (`ki-quarantine://{identity}/{stage}`) instead. `retryable`, a boolean, cannot carry BR-022's three-way classification — only `RETRYABLE` maps to `true`; `REVIEW_REQUIRED` maps to `false` alongside `NON_RETRYABLE`, since "a human must act" and "retrying alone will not" are both true of it, and the full classification travels in the envelope regardless of what the shared boolean can hold. `retry_count` is always `0` and `first_failed_at`/`last_failed_at` always coincide — no retry-within-run mechanism exists (the same gap SDD-071 names for NFR-020's identical field), so there is exactly one attempt to time. | FR-119; SDD-068, SDD-070, SDD-071, SDD-073, BR-022 |
```
