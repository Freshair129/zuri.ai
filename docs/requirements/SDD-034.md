# ZAI:SDD-034

<!-- canonical-row:start -->
```text
| SDD-034 | The per-Business domain map is derived from the same Membership rows and the same tenant-wide expansion that already produce `visibleBusinessIds` and `ownedBusinessIds`, and it is populated in **every** `resolveViewer` branch: the platform DEV branch fills it from its own visible-Business set rather than carrying a "sees everything" flag, while authenticated Membership branches derive it from persisted authority, so no consumer can answer the per-Business question by reading a shortcut. `domainsForBusiness` fails closed on an unknown Business and falls back to the flat `visibleDomains` only for a viewer that predates the map (a hand-built fixture), never for one a real resolver emitted. Cost is O(visible Businesses × domains) in the viewer payload — accepted at current scale; the exit if it stops being acceptable is a Business-scoped resolution (`resolveViewer({ businessId })`), not a flag. | FR-061; FR-031, FR-038, SDD-017, SEC-008 |
```
