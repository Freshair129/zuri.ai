# ZAI:SDD-098

```text
| SDD-098 | LINE channel tokens are minted, not stored: for a vault-backed account the Integration LINE port exchanges Channel ID and Channel secret at `POST https://api.line.me/oauth2/v3/token` for a stateless 15-minute access token, caches it in process for at most 13 minutes keyed by credential version, mints at most once a minute per account and drops the cache on rotation or revocation; a long-lived channel access token is used only when the owner supplied it as an explicit override, and is validated separately so that a correct pair with a wrong token is reported as the token's fault. | FR-225; ADR-089 D3 |
```
