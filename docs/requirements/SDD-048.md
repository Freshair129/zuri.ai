# ZAI:SDD-048

<!-- canonical-row:start -->
```text
| SDD-048 | Observability is one emitter and one correlation id, not logging scattered through the call path. `src/lib/observability` exposes a structured emitter whose sink is injectable (stdout by default, captured in tests) and whose field names are **allowlisted**: safety comes from what the emitter accepts, not from scrubbing what a caller passed, because a denylist only ever knows the secrets someone already thought of. An unknown field is omitted and its *name* listed in `unsafeFieldsOmitted`, so a dropped field is visible rather than silent. The correlation id is validated before use (`^[A-Za-z0-9_-]{8,64}$`) since it arrives as untrusted input and is echoed into records. It flows route → turn → ingest → `AuditEvent.payloadJson`, which makes the audit table — not the log stream — the durable join between a webhook delivery and the rows it created. Counts and durations ride on the batch record; a metrics backend is deliberately not introduced. | NFR-017; FR-028, FR-050, FR-081, SEC-009 |
```
