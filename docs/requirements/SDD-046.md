```text
| SDD-046 | A canvas gesture is an intake surface and gets no write path of its own: a drop builds an envelope delta and runs the BR-009 chain unchanged (validate → semantic check → dry run → single transaction → audit). The `preview` stage is **relocated, not skipped** — the optimistic edge already drawn in a visibly pending state *is* the preview, since a modal on every drop would make the canvas unusable while a silent commit would drop a stage the rule requires. A clean dry run commits; a failed one reverts the optimistic edge and prints the reason at the edge rather than in a toast that outlives its context. Undo rides the audit event. A future surface that cannot honour this adds a converter, never a second write path. | FR-083, FR-084; BR-009, BR-017, SDD-008, SDD-009, ADR-035 |
```
