```text
| SDD-060 | Entity recognition is a seam with a deterministic default, not a model dependency. `extractEntityCandidates` takes an optional `recognizer`; the default recognises legal-form organisation patterns only — `บริษัท … จำกัด`, `ห้างหุ้นส่วนจำกัด …`, `… Co., Ltd.` — because in those the suffix IS the evidence: the grammar announces the type without anyone recognising the name inside it. Person, product, location and the rest of §13's type list need a model, and a model in the knowledge lane would couple Stage 8 to whatever recognises Thai and English text this month (the SDD-059 reasoning, one stage over). An empty seam was rejected as the alternative: shipping a hook with nothing behind it is what makes Stage 15 embedding read as delivered when it is not, and this requirement declines to repeat that shape. `normalized_name` is lexical and uses only the mention itself — trim, collapse, strip the legal wrapper. The moment it consults a registry, a catalogue or the other candidates in the batch it has begun deciding two mentions are one thing, and that decision is Stage 9's. | FR-113; FR-109, FR-112, SDD-059, ADR-050 |
```
