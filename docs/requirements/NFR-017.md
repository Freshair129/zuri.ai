# ZAI:NFR-017

<!-- canonical-row:start -->
```text
| NFR-017 | The LINE ingress is traceable end to end from one correlation id: every batch carries a correlation id — accepted from the trusted transport owner when it presents a well-formed one, generated otherwise — that appears on every structured record the request emits, on the HTTP response, and on the durable audit row for the message it produced, so an operator can join `webhook → identity → conversation → message` without archaeology. Records are emitted through one allowlisted emitter: message text, display names, bearer tokens, binding ids and reply tokens can never reach a log line, and a field the allowlist does not know is dropped and named rather than printed. Every rejected batch and every failed event emits a record naming the stage that failed; no failure is silent. | FR-028/050/052/081 observability gate; SDD-048 |
```
