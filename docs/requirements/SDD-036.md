| SDD-036 | Board and Schedule are **derived views over models other requirements already own** — WorkItem (FR-005), Project (FR-003), Milestone (FR-006). Neither introduces a persisted aggregate, an ordering column, or a second write path: a card opens the existing editor, and a bar is computed from dates the owning model already stores. Where such a view enumerates a vocabulary it does not own, it derives that vocabulary from `src/lib/validation/enums.js` — a hand-copied list is how a status ends up with nowhere to render. | FR-063, FR-064; SDD-019, FR-005, NFR-008 |
