| SEC-028 | Access history is authorized exactly like the grant it describes, and refuses the same way: `ownsBusiness` for a Business scope, `ownsTenant` for a Tenant scope, the caller themself for their own history, or the installation operator — with no other path. A scope the caller does not own and a scope that does not exist answer the identical 404, so the read surface cannot be used to enumerate other tenants' or businesses' ids (SEC-001). No new authority is created for this: every check reuses an existing exported predicate. | ✅ implemented 2026-09-12 — FR-199 / ADR-080 D3/D4 |
