```text
| FR-171 | Execution Trace & Replay v0.3 — the agent domain owns one scoped append-only `AgentTraceEvent` journal for the native SERVER LINE path. It records one event per actual turn input, model call, tool/action invocation, retrieval, memory or delivery observation, separating UUID `turnId`/`executionId`/`instanceId`/opaque MSP `sessionId`/`ctxId` from stable tool registry/action-intent ids, fresh model/tool/action/send attempt ids, document/artifact versions, retrieval/memory references and delivery receipts. Runtime instanceId is process-stable; executionId changes per claimed attempt. It reuses `LineConversationJob.id` as `turnId`, stores exact semantic input snapshots up to 1 MiB plus SHA-256 and explicit retention/redaction states, keeps provider usage subsets, timestamps and recipient evidence nullable/truthful in UTC, and returns owner-only, `line-oa`-visible read-only playback at `GET /api/line-oa/jobs/{id}/trace`; missing retention makes playback `REPLAY_INCOMPLETE`, and playback performs no effects. Native SERVER defaults to no private memory adapter: jobs without the approved immutable per-job opt-in retain empty memory refs plus `EXCLUDED_BY_POLICY`, while opted-in worker jobs may compose the trusted MSP thread adapter and durable local receipt checkpoint. MSP Soul/session/memory authority, GKS retrieval and optional Edge adapters remain separate external gates and receive no direct foreign DB writes. | 🟡 native SERVER P1 and approved worker composition implemented locally under ADR-070/ADR-061; MSP erasure API, live Postgres and deployed canary evidence remain pending |
```
