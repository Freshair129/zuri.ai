# Retired Developer Delivery Control policy (historical)

**Status:** Retired by [ADR-113](../../decisions/ADR-113-RETIRE-DEVELOPER-DELIVERY-CONTROL.md) on 2026-10-22.

This compatibility path is retained so historical links resolve. The former
autonomous v4 procedure is no longer active and must not be used to admit,
dispatch, constrain, or assess current repository work. Its former task
preflight, controller, supervisor, model policy, worker observations, and
receipts have been retired from the active repository workflow.

Current repository delivery uses [AGENTS.md](../../../AGENTS.md), the scoped
[verification policy](../VERIFICATION-POLICY.md), normal Git review, and the
existing required hosted CI. This record does not replace or change business
Project Manager approval workflows, document governance, or environment-specific
release authority.

The earlier policy text remains in Git history. Frozen records under this
directory and `SOURCE-RECONCILIATION.md` are historical evidence only.
