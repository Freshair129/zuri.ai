# Retired repository-local DDC controller (historical)

**Status:** Retired by [ADR-113](../../decisions/ADR-113-RETIRE-DEVELOPER-DELIVERY-CONTROL.md) on 2026-10-22.

This compatibility path is retained for old links only. The repository-local
controller, task preflight, supervisor, worker dispatcher, and worker
observation projection described by its former contents are no longer active
and have been removed from the source tree. Do not start or install that
controller from historical artifacts.

The former design is preserved in Git history and its frozen receipts remain
historical evidence. It is not the source for business Project Manager work,
product approvals, document governance, verification selection, or required
repository CI.
