| FR-210 | A verified staff sender adds or matches SKUs from LINE with a deterministic `#sku` command that previews before it writes — the server-owned LINE worker's answer port is wrapped so that a DIRECT-chat text beginning with `#sku` is answered by the command before the model, and every other message is answered exactly as before. The command acts only when the sender's LINE channel identity for that account is verified (FR-097) and the viewer resolved from that person has Inventory write authority in the account's Business (BR-042); for anyone else — unverified, a customer, a member without write authority, a group or room — the message falls through to the normal answer. `#sku` with `key: value` lines in Thai or English (items separated by `---`; a run of 8, 12, 13 or 14 digits under บาร์โค้ด is declared a GTIN so a typo is refused by its check digit) builds the FR-208 envelope with channel LINE_OA and correlation `line:<account>:<event>` and replies with the preview; an unknown key is reported by line number and nothing is previewed. `#sku ยืนยัน <code>` commits and `#sku ยกเลิก <code>` cancels, both only for the person who previewed; every refusal becomes a Thai reply rather than a failed LINE job, and a reply stays under the LINE limit with the confirmation or fix instruction always kept. No model output reaches a write; the adapter adds no authority (SDD-091). | 🟠 implemented locally 2026-09-13 (ADR-084 D4) — `inventory/import/catalog-line-command.js` (parser, reply formatters), `agent/line-catalog-command.js` (`withLineCatalogCommand`, `lineCatalogViewer`), `api/line-oa/worker/route.js` wraps the answer port; `tests/unit/inventory-catalog-line-command.test.js`, `tests/unit/agent-line-catalog-command.test.js`, `tests/integration/fr210-line-catalog-command.test.js`; production migration shared with FR-208 and APPLIED 2026-09-13; main ada5188b deployed (the `#sku` command is live on the server-owned LINE worker) |
