### [ZAI:FR-149 canonical record](requirements/FR-149.md)

> Server-owned LINE conversation transport — native signed webhooks resolve an explicitly enabled CLOUD account, record each event as Integration evidence and acknowledge LINE on that durable capture, admit it asynchronously into inbound CRM and a uniquely keyed conversation job in one transaction, and use the Integration-owned LINE port to send and record provider acceptance. An admission abandoned by process exit is not lost: the evidence row is labelled `ADMITTING` before the first attempt, and the bounded worker tick re-admits rows stranded there from the stored payload. A reconciled event carries no reply token — evidence strips it, and LINE's token is dead long before a reconciler runs — so it is delivered by Push where the account permits delayed Push, and otherwise ends `FAILED` visibly rather than silently. Terminal `FAILED` jobs are counted with their `errorCode` for the selected Business on the Studio conversation surface, so a customer who received no answer is visible without a database query. One worker tick answers several waiting customers at once and delivers several ready answers in turn, so nobody is queued behind another customer's model call, and the supervisor's polling cadence follows the work — quick while there is any, backing off while there is none, with admission waking it directly when it queues a job. Per-account ownership fencing, immutable send payload, bounded retries, secret redaction and receipt recovery prevent duplicate or falsely reported sends.

### [ZAI:FR-150 canonical record](requirements/FR-150.md)

> Optional Edge conversation execution — account execution placement is SERVER or EDGE independently of LINE transport. Business-authenticated devices pull versioned, leased, minimized conversation jobs and return text; they receive no LINE credentials, recipient identifiers or send authority. Offline Edge leaves durable waiting work; no automatic transfer to an external model. Negotiated v2 claims carry the server-owned reply answer deadline and remaining execution budget; Edge subtracts transit and elapsed time from one whole-turn budget, preserves v1 compatibility and never interprets a lease as a reply deadline (owner-approved LINE-OA-LOCAL-LLM-CIN-EXECUTION, 2026-09-17).
