| FR-219 | Task card evidence badges and subtask progress: every task card on `/control/roadmap` shows DOC, CODE and TEST badges from its Task Container links, FR, NFR and FEAT badges from the ids it delivers (the container's `delivers` list, else the ids named in its title with ranges expanded) read against the FR-124 snapshot, and badges for its domain code name, complexity and priority. Each evidence badge is green when done (a resolving link on a done task; every id `verified`, FEAT `ready`), orange when in review (a resolving link on a task in review; any id `partial`), red when it needs fixing (a declared link whose path no longer exists; an id the snapshot does not know; a done or review task delivering an id still `planned`, `blocked` or `not_implemented`) and gray when empty, always with a word beside the colour; the descriptor badges are neutral. Link existence is checked by `scripts/programme-containers.mjs` when it generates the container module, whose check mode is under test. A container that lists subtasks (`P0`, `P1`, …, each with a title and status) has them listed on the card with a progress bar computed under the board's status mapping; a task without subtasks shows no bar (ADR-086 D6). | ✅ deployed (merged #383, 6630c1df; ADR-086 D6) — `scripts/programme-containers.mjs`, `modules/platform-control/program-task-evidence.js`; `tests/unit/program-task-evidence.test.js`, `tests/unit/programme-containers.test.js` |
