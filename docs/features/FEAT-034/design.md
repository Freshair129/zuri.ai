### [ZAI:FR-217 canonical record](requirements/FR-217.md)

### [ZAI:FR-218 canonical record](requirements/FR-218.md)

> Programme usage report endpoint: `POST /api/platform/programme-usage-reports` lets an agent without local logs report one session's usage for one programme task — source, session id, task id, model, input, cache write, cache read and output tokens, request count, start and end time and active minutes — authenticated by the deployment bearer `ZURI_PROGRAMME_USAGE_TOKEN` (at least 32 characters, compared in constant time). A report is stored once per `(source, sessionId)` in `ProgrammeUsageReport`: the same payload again is an idempotent replay, a different payload for the same key is refused with 409, an unknown task id and an invalid body are refused by name, and a missing or wrong bearer answers 401 without reading the body. `/control/roadmap` reads the reports on the server and merges them with the meter's figures, skipping any report whose `source:sessionId` the meter already counted, and still renders when the table is absent. The Supabase migration ships with it; applying it on production is a separate operator step (ADR-057; ADR-086 D5).

### [ZAI:FR-219 canonical record](requirements/FR-219.md)

> Task card evidence badges and subtask progress: every task card on `/control/roadmap` shows DOC, CODE and TEST badges from its Task Container links, FR, NFR and FEAT badges from the ids it delivers (the container's `delivers` list, else the ids named in its title with ranges expanded) read against the FR-124 snapshot, and badges for its domain code name, complexity and priority. Each evidence badge is green when done (a resolving link on a done task; every id `verified`, FEAT `ready`), orange when in review (a resolving link on a task in review; any id `partial`), red when it needs fixing (a declared link whose path no longer exists; an id the snapshot does not know; a done or review task delivering an id still `planned`, `blocked` or `not_implemented`) and gray when empty, always with a word beside the colour; the descriptor badges are neutral.
