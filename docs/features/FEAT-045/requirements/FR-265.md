| FR-265 | LINE OA Studio conversation work is server-executed only. `EDGE` leaves the account's transport and execution vocabulary: `transportMode` admits CLOUD alone, `executionMode` is always SERVER, and the `SWITCH_TRANSPORT_MODE` action is withdrawn. A separate durable `LineOaAccount.runtimeOwner` defaults to SERVER; admission snapshots it onto each `LineConversationJob`, and only an opted-in conversation eligible for the Conversation Runtime may be admitted with `runtimeOwner=CONVERSATION_RUNTIME` (ADR-106 D3 and its 2026-09-27 amendment: a direct, group or room audience, from a verified or an unverified sender; an unverified sender's job runs with no person). Ineligible work stays in the SERVER cohort. Owner changes use `CONFIGURE_EXECUTION` and require the account's outstanding jobs to be quiescent; environment flags or process readiness never determine ownership. Core remains authoritative for admission, claims, leases, receipts, state transitions and side effects in both cohorts; the runtime invokes turns only through strict Core ports. The `modelAccess` LOCAL_ONLY branch is removed with EDGE: it never called a model, but substituted a deterministic canned answerer, so an account left on it replied to real customers without inference. The Edge conversation-job surface — claim, context, tools, complete, fail — and model-residency directive are withdrawn as routes; historical `LineConversationJob.executionMode=EDGE` remains readable and is never newly written. ADR-110 D1 later retires Zuri-owned device pairing, Edge credentials and Edge extraction surfaces; D3 preserves existing records and schema. | 🚧 deployed 2026-09-21 (PR #500 `cfb62da3`; migration `20260921090000` applied; production main `5c5f12d3`; TASK-ZAI-120, ADR-100, FEAT-045) — production receipt NOT_RUN |
