# ZAI:FR-267

<!-- canonical-row:start -->
```text
| FR-267 | A Business owner may choose the operator's Private Runtime Platform (PRP) as the model provider for its LINE answers, so a customer's message is processed on the operator's own GPU and reaches no external provider: provider code `prp` on the FR-266 route, offered only when the operator has configured the runtime's base URL on the server (`ZURI_PRIVATE_RUNTIME_BASE_URL`, HTTPS, no credentials, query or fragment) and never an endpoint a browser can supply. The Business's PRP client key is proved against PRP's `GET /v1/models`, which lists the model aliases granted to that key: 401/403 refuses the key, a chosen alias absent from the list refuses the model, and nothing is stored on either. Answers use PRP's OpenAI-compatible `POST /v1/chat/completions`; a reasoning block the model emits (`<think>…</think>`) is removed before the text can reach a customer, and an answer that is only an unfinished reasoning block fails closed rather than being sent. PRP's own "no eligible node" and deadline refusals fail the answer — there is no fallback to an external provider. | 🚧 deployed 2026-09-21 (PR #520 `f9ea5c88`; private runtime settings on production; TASK-ZAI-121, ADR-100 D7) — no PRP key saved yet; production receipt NOT_RUN |
```
