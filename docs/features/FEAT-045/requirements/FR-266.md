| FR-266 | A Business owner provisions the model provider API key from the browser, write-only, without an operator or a host file: `POST /api/integration/model-providers` takes a provider code and an `apiKey`, proves the key live against that provider before anything is stored, then writes it through the Integration lane's `SecretStorePort` as a `MODEL_PROVIDER_KEY` credential (FR-242) on a Business-scoped `IntegrationConnection` whose purpose is MODEL_PROVIDER. Rotate, revoke and re-validate follow the FR-223 lifecycle and the FR-224 write gate — AAL2 step-up and rate limit — unchanged. The key has no non-secret identifier, so its display hint is always null (SDD-101) and no response, log or audit payload carries any part of it (SEC-030, SEC-033). No new table: the connection, credential and version models already exist. | 🚧 deployed 2026-09-21 (PR #500, hardened by #518 and #522; production main `5c5f12d3`; TASK-ZAI-120, ADR-100 D4, D8) — no Business key saved yet; production receipt NOT_RUN |
