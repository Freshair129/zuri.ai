| FR-178 | Disassembly is a work order run backwards and it cannot launder branded stock — de-kitting issues the finished set and receives its constituent components in one transaction at a stated location. A component that was branded returns as its own `CUSTOM_COMPONENT` identity with its customer lock intact, or goes to `TH_QUARANTINE_SCRAP`; it never returns as generic raw stock. Packaging the disassembly destroys is written off in the same transaction rather than optimistically returned, and the destroyed lines are named by the caller because only a person looking at the box knows which they are. | 🟠 implemented locally 2026-09-10 (ADR-074 D6) — `application/de-kitting-service.js`; `tests/integration/fr178-de-kitting.test.js` |
