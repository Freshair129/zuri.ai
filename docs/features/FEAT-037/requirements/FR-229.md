```text
| FR-229 | Non-text LINE content in the CRM record: admission stops skipping non-text events. A sticker, location, image, video, audio or file message becomes a CRM `Message` with a content kind and a fixed placeholder body, and a media message also gets a `MessageAttachment` recorded without bytes; follow, unfollow, join, leave, member joined, member left, postback and unsend become `ConversationEvent` rows whose bounded payloads carry ids only. None of them creates an answer job, and an unsend tombstones the referenced message body and attachment. Fetching media bytes into `FileAsset` within LINE's retention window is a later phase; until then no bytes are stored. | ✅ built 2026-09-14 (ADR-091 D5, FEAT-037, TASK-ZAI-088) — the ADR-061 native admission seam (`line-conversation-jobs.js`) no longer skips non-text events; `MessageAttachment`, `ConversationEvent`, `Message.contentKind` in the schema (migration `20260914150000`, not applied); the legacy `/api/agent/line-webhook` seam still skips them inline and is unchanged |
```
