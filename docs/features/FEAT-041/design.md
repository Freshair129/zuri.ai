> Chat evidence cold archive: before the FR-230 retention sweep tombstones a `MESSAGE_BODY_AND_ATTACHMENTS` row it writes the row to a local write-once archive, and it tombstones only rows whose archive file has been written, flushed, read back and verified; if any archive step fails, nothing is tombstoned for that Tenant and the run's audit event counts the failure. Only the CRM record is archived; raw LINE payloads, agent traces and MSP content stay delete-only. An archived message is kept until it is 10 years old and then destroyed.
