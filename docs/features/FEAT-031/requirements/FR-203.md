| FR-203 | A barcode, GTIN, supplier code, manufacturer part or legacy code is an attribute of exactly one SKU, and an intake resolves an identifier before it creates anything (BR-002): `ProductIdentifier` (`kind` GTIN / BARCODE / SUPPLIER_CODE / MANUFACTURER_PART / LEGACY_CODE, `value`, optional `issuer` and the pack `unit` the barcode is on, ACTIVE / RETIRED, `version`) is unique per `(tenantId, kind, value)`, the two scannable kinds share one value space (`INVENTORY_IDENTIFIER_TAKEN` names the SKU that holds it), a GTIN must be 8 / 12 / 13 / 14 digits with a valid mod-10 check digit (EAN-13 and UPC-A are GTIN-13 / GTIN-12, not separate kinds), a retired value still blocks (GS1 never reuses one), and none of them is ever a key or an `ExternalRef`. `GET/POST/PATCH /api/inventory/products/[id]/identifiers` manage them; `GET /api/inventory/products/resolve?identifier=` answers which SKU a value names — the `code`, the FlowAccount code or any active identifier, in that order — follows a merged duplicate to its survivor, reports the pack factor when the identifier names a unit, and answers `{ product: null }` with 200 on a miss. | 🟠 implemented locally 2026-09-13 (ADR-083 D3) — `ProductIdentifier`, `isValidGtin` / `identifierCollision`, `inventory-identity-service.js` (`addIdentifier`, `applyIdentifierAction`, `listIdentifiers`, `resolveProduct`), three handlers; migration `20260913120000_inventory_sku_governance` APPLIED on production 2026-09-13 (owner-instructed, ADR-057; ledger row written, effect verified: 3 + 6 columns, both tables with forced RLS, 0 masters to backfill) and main 52c9881e deployed; AC-203.1. Console surface 2026-09-13: the SKU detail page `/inventory/products/[productId]` lists, adds (a failing GTIN check digit is caught in the form) and two-step retires identifiers, and names the SKU that already holds a refused value by asking `resolve`; the dashboard's SKU codes open that page and its lookup box resolves a scanned code to its SKU (`inventory/ui/sku-console.js`, `tests/unit/inventory-sku-console.test.js`, `tests/unit/inventory-product-page.test.js`, `tests/e2e/fr203-sku-identifiers-console.spec.js`) |
