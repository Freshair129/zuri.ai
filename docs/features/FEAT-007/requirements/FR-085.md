| FR-085 | Contract-gated release on the Board: a WorkItem governed by an effective ordering successor whose declared contract is unsatisfied or invalid is **held**, and says so on its own card — naming the predecessor it waits for as a link, before the user attempts the move rather than as a refusal after it. Protected entry is IN_PROGRESS/REVIEW or DONE, including creation/import; existing statuses are not rewritten by evidence changes. An edge whose contract is `undeclared` (a row predating FR-084) does not hold anything: it is surfaced for backfill, never enforced retroactively, because turning a data-migration gap into a production stoppage is the worse of the two failures. | 🔜 approved planned — C0 v0.1.5 adopted 2026-10-24; implementation evidence remains separate |
