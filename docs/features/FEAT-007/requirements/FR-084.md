| FR-084 | Handoff Contract on a dependency edge: every `Dependency` carries a declared contract stating the **deliverable** the predecessor owes and the **acceptance** condition that says the debt is paid. Acceptance either references an existing `Gate` — whose status is then the single source of truth (ADR-035 D2) — or carries an explicit satisfied/unsatisfied mark with provenance. Strict V1 client/persisted shapes, server-owned manual Person/time/audit provenance, predecessor-scoped Gate references and content-hash CAS follow the accepted Pipeline contract foundation v0.1.5 section4. Persisted as one nullable JSON column with a Zod schema at the boundary (SDD-008); no new aggregate and no new model ownership, `Dependency` already belonging to the `project-manager` charter. Nullable at rest because rows predating the column exist: the invariant is enforced at the creation surface, and an edge with no contract renders as `contract undeclared` rather than looking complete (ADR-035 D6). | 🔜 approved planned — C0 v0.1.5 adopted 2026-10-24; implementation evidence remains separate |
