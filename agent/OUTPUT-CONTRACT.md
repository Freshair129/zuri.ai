# Agent Output Contract

After each phase create a report containing:

```text
Phase
Status: PASS / PARTIAL / BLOCKED

Implemented
Changed files
Database changes
Tests run
Test results
Screens/routes verified
Known issues
Decisions made
Next phase
```

Do not use vague statements such as "everything looks good".

For FINAL include a matrix of every Acceptance Criterion with PASS/FAIL and evidence.
